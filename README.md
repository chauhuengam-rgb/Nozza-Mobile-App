# Nozza Launcher 📱

A minimalist custom home screen and mobile launcher designed for React Native and Expo.

## 🚀 Features
- **Clean Aesthetic:** Sleek dark-mode interface with a modern grid layout.
- **Widgets:** Built-in real-time clock, date, and weather status card.
- **App Shortcuts:** Quick access groups for Workspace & Study and System utilities.
- **Interactive Alerts:** Responsive touch feedback for launching shortcuts.

## 🛠️ Built With
- **React Native**
- **Expo**
- **JavaScript**

## 🏃‍♂️ How to Run
1. Open this project on [Expo Snack](https://snack.expo.dev/).
2. Preview instantly via Web, iOS, or Android emulator.
